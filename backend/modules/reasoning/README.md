# 推理模块

基于当前上下文、记忆与证据生成 answer / action / needs_input 决定。推理不直接执行工具或修改业务数据库，业务动作交给 Action。

生产使用 DeepSeek Flash 的 none / low / high。主模型 auto 选择工具，可以直接交付完整最终正文；等待补充使用显式控制，阶段交付与系统受阻显式标明状态及剩余工作。控制由模型适配层解释，不注册到 Action，不固定增加规划或评审调用。

系统、任务、证据、交付提示在 defaults.toml。工具正常、部分、空和错误回执都作为真实观察进入下一轮；操作完成不能直接推断整体任务完成。同批 action_id 必须唯一。

context_inventory 表达当前真正可见的材料和近期操作。最新用户补充及续做状态位于索引之后，参与同一完整请求预算。来源引用、历史已读与本轮正文可见分开处理。

供应商思考续接经 ModelContinuationPort 按 Run 隔离，模块不解释隐藏推理。私有协议数据不进入公开流、普通 Trace 或业务记忆正文。当前完成判断依赖模型与结构检查，尚无独立语义裁判；专业结论仍需依据与验收。

边界见[当前架构](../../../docs/architecture.md)，验收定义在[测试集](../../../datasets/README.md)。
