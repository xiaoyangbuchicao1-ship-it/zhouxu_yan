# 海事论文文献检索

这个 Skill 用于在只读模式下检索并梳理已核验的海事法学术论文信息卡与公开文献线索。它只组织检索顺序与引用边界，不写入工作区文件，也不编译生成 PDF/Word（如需撰写并编译正式论文，请使用工作模式的 `csl-law-paper-generator`）。

## 适用时机

当用户寻找海事法学论文观点、学者学说争议、实证研究发现或特定主题的学术综述线索时，先调用 `read_skill` 读取本 Skill，再直接执行信息卡检索，不要重复调用 `capability_card_select`。

## 检索与核验顺序

1. **学术信息卡召回**：调用 `information_card_search` 提交简短明确的研究主题或学者关键词，取得候选信息卡、来源文献标题、作者线索、发表时间与 PDF 页定位。
2. **精读完整卡片**：对最相关的 2 至 5 张候选卡调用 `information_card_read`，读取完整论点、前置条件与原文来源定位，保留前端可回溯的卡片来源引用。
3. **缺口补核**：若论文信息卡仅包含研究片段而用户追问连续期刊印刷页码或公开全文背景，可按需调用 `web_search` 与 `web_read` 补充公开出处；未取得原文印刷页码时如实留空，严禁将 PDF 物理页数直接改写成期刊印刷页码。
4. **法源分离**：涉及“现行法律规定是什么”或“法院实际如何裁判”时，必须分别调用 `dynamic_rag_search` 与 `search_cases`/`read_case`，严禁将论文中的修法建议或学者观点写成现行法律。

## 证据边界与禁令

- 严禁把 `card_id`、内部文件路径、`source_path` 或工具名称写入面向用户的正文。
- 检索结果 `status=partial` 或 `method=bm25` 时，如实告知当前主要基于关键词召回结果，不夸大覆盖面。
- 清晰区分【学术文献观点】、【现行实定法依据】与【司法裁判认定】。
