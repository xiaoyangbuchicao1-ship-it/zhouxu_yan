# Agent Harness

负责 Agent 任务生命周期、主循环、回合执行、消息介入、暂停、恢复、停止和失败恢复。

Harness 通过 A 方案最小接口编排八个 Agent 模块，不依赖具体数据库驱动或模型供应商 SDK。它生成调用标识，读取模块结果并决定下一步调用谁。顺序、并行、重试、暂停、恢复、取消和终止等运行能力按实际流程逐步实现。

Harness 记录基本调用事件，可选观测缺失不阻断业务。必要结果失败时，不把它当作成功输入传给后续依赖步骤。模块不能绕过 Harness 直接调用其他模块内部实现。

调用边界见[模块接口契约](../../docs/module-contracts.md)。
