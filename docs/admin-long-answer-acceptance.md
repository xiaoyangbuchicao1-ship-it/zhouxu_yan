# 管理员公开回答与长内容预览验收

日期：2026-11-22  
范围：隔离预览分支 `codex/dynamic-admin-preview`，正式分支和正式运行数据未修改。

## 这次解决的问题

管理员登录失败时，错误提示用了和字段错误相同的负上边距，文字会贴住并侵入登录按钮。现在两种错误各自使用自己的间距，提示位于按钮下方。

管理员会话详情原本虽然有回答字段，但没有专门处理很长的公开回答。现在接口继续返回完整的公开回答；页面默认展示可快速浏览的正文片段，超过 1200 个字符时提供“展开完整回答”，展开后显示原文，再次点击可以收起。暂停任务使用已经生成的完整片段。

工作台的长回答保留窄阅读栏，增加稳定的滚动锚点和更自然的段落换行，减少流式更新时页面跳动。
