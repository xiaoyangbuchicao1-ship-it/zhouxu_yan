## 人话版黄金测试结果

### 1. 上传一个完整技能包

**测什么：** 在网页上传一个同时包含 `SKILL.md`、脚本、参考资料和 CSV 模板的 ZIP。

**防什么坑：** 只保存了一段说明文字，脚本和资料却在上传后丢失；或者刚上传就偷偷执行脚本。

**实际结果：** 损坏 ZIP 被明确拒绝，超过 20 MB 的文件被拒绝，约 1.2 MB 的正常 ZIP 成功保存。上传本身没有调用模型，刷新页面后技能仍在“我的技能”里，包内文件可以逐个查看。

### 2. 按技能包原脚本生成 CSV

**测什么：** 输入港口费 12.50 元和资料费 7.50 元，让官方 DeepSeek 读取规则、写入 JSON，再调用包内 `summarize.py`。

**防什么坑：** 模型自己口算或重写脚本，却把一段文字说成已经生成文件。

**实际结果：** 真实脚本在隔离环境运行，生成并下载了 `expense-summary.csv`。文件内容是港口费 12.50、资料费 7.50、合计 20.00；下载内容的 SHA-256 与服务端记录一致。

### 3. 离开页面再回来

**测什么：** 任务运行时离开页面，完成后重新打开对话并刷新。

**防什么坑：** 页面一关任务就丢失，刷新后重复执行，或者只显示前端假状态。

**实际结果：** 仍是同一个 Run，产物和执行回执都保留，脚本没有再次执行。

### 4. 失败时把真错误告诉用户

**测什么：** 运行一个明确缺少模板的失败脚本。

**防什么坑：** 把失败吞掉、交付旧文件，或让模型编一个成功结果。

**实际结果：** 脚本只执行一次，页面显示原始错误 `SKILL_TEST_FAILURE: 缺少必需模板`，没有生成任何交付文件。测试同时核对了 stderr 和 `EXIT=1` 的退出证据。

### 5. 不同账户不能越界读取

**测什么：** 用另一个账户读取前一个账户的技能和生成文件。

**防什么坑：** 只在页面隐藏按钮，但后端接口仍能读到别人的内容。

**实际结果：** 另一个账户读取私有技能和产物都被拒绝。
