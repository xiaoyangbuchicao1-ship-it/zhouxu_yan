# 论文资料进入侧栏验收记录

日期：2026-11-21。入口为 Docker Linux Compose 的 `http://127.0.0.1:18080`。

## 这次修了什么

原来论文检索虽然能返回结果，但运行记录只会把法规和案例投影成资料卡，论文结果被留在工具回执里，所以右侧资料栏看不到论文。论文详情接口也没有论文来源的读取路径。

本次把论文卡片接入同一套来源合同：保存论文题目、作者、年份/来源集、页码或章节定位，并按卡片编号读取对应正文。首次读取大文件时，扫描论文卡片文件放到后台线程，页面和健康检查不会被同步磁盘读取卡住。资料卡展示前会清掉原始导出中的 HTML 标记，避免标题显示成代码。

| 测试 | 测什么 | 防什么坑 | 实际看到的效果 |

## 实际验证

- 正式浏览器脚本：`node tests/browser/paper-sources.mjs .ai-tmp/paper-source-formal-final-20261121`
- 结果：5 项检查全通过；论文标题“2007年中国海事法学研究综述”，作者“李志文，汪永利，史强”，来源集“2007”；论文正文接口返回 385 个字符；页面脚本错误为 0。
- Docker 回归：`backend.harness.graph.test_tool_contract` 与 `backend.interfaces.api.test_health` 共 4 项通过。
- 静态检查：Python 编译、前端 TypeScript 类型检查、`git diff --check` 通过。
