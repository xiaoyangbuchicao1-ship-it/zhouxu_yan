# 后端八规范

适用范围：本项目后续后端开发、重构及维护任务。本文是 `AGENTS/` 规范知识库的一部分，由根目录 `AGENTS.md` 引用。

## 1. 动手前：三条强制检查

- **约束1：先列计划，批准再动手**：要求AI在执行任何任务前，必须先列出详细步骤，等待用户明确批准后才能开始，相当于安装一个“强制暂停键”。
- **约束2：改之前先读文件**：强制AI在编辑任何文件前，必须重新读取当前文件内容，避免依赖可能已过时的记忆。
- **约束3：别重复造轮子**：要求AI优先寻找并利用项目中已有的函数和抽象，禁止重新实现已有的功能。

## 2. 执行中：三道脱轨干预

- **约束4：不确定先说，不要猜**：当AI遇到没有先例可循的情况时，必须停下来询问，禁止自行猜测需求并继续。
- **约束5：中途转向，先问再动**：如果执行过程中发现原计划走不通，AI必须停下来汇报并重新制定计划，获得确认后才能继续，严禁擅自改变方向。
- **约束6：计划外的问题先报告**：在任务执行中，如果发现与当前任务无关的代码问题或可疑行为，AI必须报告出来，严禁自作主张地顺手修改。

## 3. 交付时：两道验货关卡

- **约束7：改了什么必须汇报**：在提交改动前，AI必须向用户完整展示所有更改的差异（diff），并获得明确批准，确保修改完全透明。
- **约束8：没跑过测试不算完成**：在宣布任务完成前，AI必须针对改动部分运行最小范围的自动化验证（如lint、类型检查、测试），确保基本质量。
